# VOICE RATE 🎙️ — Ankush Kirana

बोलकर प्रोडक्ट का रेट डालें, और बोलकर भाव पूछें।

- **मालिक मोड (PIN):** "शक्कर 45 किलो" बोलें → रेट सेव। फिर से बोलेंगे तो पुराना रेट हटकर नया आएगा। नया प्रोडक्ट सीधा जुड़ जाएगा।
- **हेल्पर मोड:** "शक्कर का भाव?" / "साखर किती?" → स्क्रीन पर दिखेगा और ऐप बोलकर बताएगा।
- हिंदी + मराठी मिक्स, ऑफ़लाइन PWA, Gold-Silver डिज़ाइन।
